# 饥饿围城：ALL清除计划 v4.3

一款基于**天冬酰胺酶（Asparaginase）治疗急性淋巴细胞白血病（ALL）**微观药理过程的实时资源策略游戏。
玩家操控「酶解英雄」，切断 ALL 癌细胞的外源营养，迫使其饥饿凋亡，同时控制自身凝血毒性风险。

## 运行方式

**双击打开 `index.html` 即可**（单文件 + `img/` 素材 + `audio/` 三首背景音乐，零外部依赖）。进度、语言、键位、音量、科普标记与无尽最高分通过 `localStorage` 持久化。或通过游戏链接https://vivi-alan.github.io/Asprout/进行游玩。

## v4.3 新增

### 🎵 音频系统
- 内置三首背景音乐，随界面自动切换并**循环播放**：
  - **Title_Music.wav**：标题页 / 科普教程 / 结算
  - **Level_Music.wav**：关卡选择界面 / 无尽三选一与休整
  - **Game_Music.wav**：关卡内战斗（含无尽 Boss 战）
- 设置菜单中的**音量滑条**控制总音量，存本地下次沿用

### ⚙️ 全局设置菜单
- 设置入口出现在**三个位置**：标题页（⚙️ 按钮）、关卡选择界面、局内暂停菜单（第 4 个按钮）
- 半透明设置窗口：**音乐音量滑条** + **键位设置**板块
- 点击窗口外部或按 **ESC** 关闭；音量与键位自动保存

### ⌨️ 键位自定义
- 可自定义：上 / 下 / 左 / 右移动、射击、冲刺、大招、暂停，共 8 个动作
- 点击动作行的当前按键 → 进入"按下新键…"状态 → 按新键完成绑定
- 新键与其他功能冲突时弹出 **「该按键已被占用，是否替换？」** 确认，替换后原动作清空（显示"未绑定"）
- 键位配置存本地，**重置存档时恢复默认**（WASD 移动、J/鼠标左键射击、空格冲刺、大招 Q、ESC 暂停）
- **移动端不显示键位自定义**

### 🏠 返回主页
- 关卡选择界面左上角新增 **「🏠 返回主页」** 按钮，所有难度标签页均显示，点击返回标题页（进度已自动存储）

### 💪 无尽 Boss 难度降低
- Boss 饥饿上限 **300 → 200**
- 拾取补给球：普通敌人 +15，**Boss 额外 +10（共 +25）**
- 救援信号弹成功：普通敌人 +10，**Boss 额外 +15（共 +25）**
- **箭矢命中 Boss 每次额外削减 2 点饥饿**（每支箭独立计算）

### 🐢 关卡初期优化
- 每一关**前 5 秒**敌人移动速度降为原来的 **75%**，给玩家反应时间；**无尽模式不受影响**

## 操作说明

| 操作 | 默认键 | 效果 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 移动英雄（可在设置中自定义） |
| 冲刺 | `空格` / `Shift` | 3.5 倍速 0.2s、穿敌无视碰撞 |
| 射击 | `J` / 鼠标左键 | 鼠标独立控向；穿透 3 目标、击退、硬直、自动追踪 |
| 大招 | `Q` | 清空 Asn、敌军饥饿 +20、风险 +25%，5s 强化 |
| 暂停 | `ESC` | 暂停菜单（继续/重开/设置/退出） |

## 已知说明

- 浏览器自动播放策略：首次点击或按键后背景音乐才解锁播放（静默失败兜底）
- 移动端不显示键位自定义；触控层仅局内显示
- 冲突替换后，被替换动作显示"未绑定"，可再为其指定新键
- 前 5 秒减速含分裂体；无尽模式（波次/Boss）无减速
