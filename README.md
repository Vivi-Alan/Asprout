# 饥饿围城：ALL清除计划 v4.2

一款基于**天冬酰胺酶（Asparaginase）治疗急性淋巴细胞白血病（ALL）**微观药理过程的实时资源策略游戏。
玩家操控「酶解英雄」，切断 ALL 癌细胞的外源营养，迫使其饥饿凋亡，同时控制自身凝血毒性风险。

## 运行方式

**双击打开 `index.html` 即可**（单文件 + `img/` 素材，零外部依赖）。进度、语言、科普标记与无尽最高分通过 `localStorage` 持久化。

## v4.2 新增

### 🌐 语言切换
- 标题页新增 **Language / 语言** 按钮，游戏中英文一键切换

### 🟢 简单模式
- 初始即解锁，与普通/困难并列（选关界面「简单」标签）
- 数值大幅宽松：刷新间隔 = 普通 1.5 倍（10.5s 起）、移速降至普通 70%（约 70px/s）、同屏敌人上限 9（普通 60%）
- 玩家移速 +10%、射击冷却 0.25s、大招蓝耗 20、风险增幅 15%
- 简单模式通关**不解锁**本关普通进度，全部通关也不解锁无尽模式

### 🔬 科学科普页（点击第 1 关触发）
- 启动直接进入标题页；**首次点击第 1 关且本地无任何通关记录**时，在教程之前全屏展示「天冬酰胺酶如何治疗 ALL」图文科普
- 正常细胞（ASNS ✓ 可内源合成 Asn）→ ALL 细胞（ASNS ✗ 依赖外源）→ 天冬酰胺酶（水解耗竭）三卡片 + 凋亡流程
- 底部总结「本游戏模拟上述机制」；点击**明白了**进入操作教程
- 已观看状态存入本地；**重置存档后再次触发**

### 🎮 操作教程页
- 紧随科普之后：WASD 键位大图 + 鼠标射击 + 空格冲刺 + 游戏目标说明
- 点击**开始战斗**进入第一关
- 选关界面右下角「📖 再次观看教程」随时重播（科普 + 教程）

### 📱 移动端适配
- 标题页「移动端」按钮：强制锁定横屏（若浏览器支持），**停留在当前界面（标题/选关）不直接进入游戏**
- 进入关卡后：左半屏**虚拟摇杆**移动；右半屏下部**冲刺按钮** + **滑动射击**（触摸滑动超 30px 朝滑动方向射箭）；**大招按钮**在左半屏摇杆上方；右上角暂停按钮
- **触控层只在局内显示**（标题/选关/结算界面不出现摇杆与按键）；触控元素半透明，无操作 5 秒淡出、触摸后重现；键盘鼠标输入仍保留
- **移动端配置持久化**：下次启动自动沿用（仍停在标题页，可点「📱 退出移动端」恢复竖屏）

### 🏆 无尽模式本地排行榜
- 无尽结束（或手动退出）时按新得分公式结算：**波次分 100×波次 + 击杀分 5/个 + Boss 额外 50 + 救援分 10/次 − 漏球惩罚 50/次（最低 0）**
- 进入前 10 自动保存（波次、得分、击杀、救援、日期），**波次优先、得分次之**排序
- 标题页「排行榜」按钮弹窗展示前 10 条，玩家最佳记录金色高亮；支持**重置（二次确认）**

### 🔑 作弊码与存档管理
- 标题页键盘输入 **ASPROUT**：解锁全部关卡与无尽模式（金色提示）
- 输入 **VIVIMYFATHER**：无敌模式（免疫漏球/减速/眩晕/失败与风险，道具无限无冷却），英雄周身金色光环 + 左上角 🛡️ GOD MODE
- 无敌期间**所有进度写入被拦截**（通关/排行榜/最高分），退出后恢复存档但已玩内容作废
- 标题页「存档管理」：查看进度信息 + **重置存档**（二次确认，清除全部本地数据并恢复初始状态）

### ⌨️ 设置
- 选关界面按 **ESC** 返回标题页

## 操作说明

| 操作 | 效果 |
| --- | --- |
| `WASD` / 方向键 | 移动英雄，面朝跟随键盘 |
| `空格` / `Shift` | 冲刺：3.5 倍速 0.2s、穿敌无视碰撞 |
| `J` / 鼠标左键 | 射击：鼠标独立控向；穿透 3 目标（衰减 20%）、击退 60、硬直 0.4、饥饿 +10、潜行者秒杀、自动追踪 |
| `Q` / 大招按钮 | 清空 Asn、敌军饥饿 +20、风险 +25%（耐药期 +35%），5s 强化 |
| `ESC` | 暂停菜单；选关界面返回标题 |

## 核心系统回顾

- **九关三难度**：简单（全解锁不记进度）/ 普通（通关解锁）/ 困难（⭐⭐）
- **五特殊敌人**：贪婪者 / 潜行者 / 攻击者 / 陷阱师 / 分裂者
- **五道具**：爱心 / 净化 / 磁铁 / 连发 / 护盾
- **救援信号弹**、**实体碰撞箱**、**无尽模式**（Boss 战 + 肉鸽三选一 + 永久成长 + 排行榜）
