# 饥饿围城：ALL清除计划 v4.1

一款基于**天冬酰胺酶（Asparaginase）治疗急性淋巴细胞白血病（ALL）**微观药理过程的实时资源策略游戏。
玩家操控「酶解英雄」，切断 ALL 癌细胞的外源营养，迫使其饥饿凋亡，同时控制自身凝血毒性风险。

## 运行方式

**双击打开 `index.html` 即可**（单文件 + `img/` 素材，零外部依赖）。进度与无尽最高分通过 `localStorage` 持久化。

## v4.1 新增

### 分裂体调整
- 分裂体**不再半透明**，尺寸改为原分裂者的 **35%**（半径约 6px，原 16）

### 潜行者速度
- 现形后高速扑球速度 **180 → 150 px/s**

### 箭矢追踪（v4.1 核心）
- 蓝箭进入敌人 **75px** 范围时启动追踪，以 **350px/s** 转向锁定最近目标（**每帧最大转向 15°**）
- 命中首个目标后若穿透次数剩余，**恢复直线飞行（450px/s）**直至生命周期结束（**2.5s**）
- **Boss 免疫追踪**；追踪目标消失时恢复直线

### 标题页（新主菜单）
- **动态背景**：深色渐变 + 漂浮半透明蓝/紫/金粒子（鼠标轻微跟随）+ 蜂窝网格线
- **标题区**：发光科技感主标题《饥饿围城：ALL清除计划》+ 副标题"天冬酰胺酶 · 微观战争 · 策略生存" + 制作团队 logo
- **按钮区**：开始游戏 / 无尽模式（9 关解锁，未解锁灰锁+提示）/ 退出游戏，垂直排列，悬停高亮、默认"开始游戏"高亮，**依次淡入**
- **底部信息栏**：左下 v4.1 · iGEM2026 UCS-B Asprout 出品；右下操作提示（WASD移动 | 鼠标射击 | 空格冲刺）+ **制作团队按钮**（弹窗显示 Zexuan Wu 与 Deepseek-v4 flash0731，点外部或 ESC 关闭）
- **交互**：↑↓ 切换按钮高亮、Enter/空格触发、鼠标悬停高亮、粒子跟随、开始游戏淡出进入选关

### 局中暂停菜单（ESC）
- 游戏中按 **ESC** 调出半透明暂停覆盖层：**继续 / 重开 / 退出**
- 暂停期间**所有游戏逻辑冻结**（敌人/计时/刷新/射击全停），渲染继续
- 再次 ESC 关闭（确认框打开时先关闭确认框）；重开与退出**二次确认**
- **继续后 3、2、1 倒计时**再开始
- 按钮支持鼠标与键盘（↑↓ 切换、Enter 确认）

## 操作说明

| 操作 | 效果 |
| --- | --- |
| `WASD` / 方向键 | 移动英雄，面朝跟随键盘 |
| `空格` / `Shift` | 冲刺：3.5 倍速 0.2s、穿敌无视碰撞 |
| `J` / 鼠标左键 | 射击：鼠标独立控向；穿透 3 目标（衰减 20%）、击退 60、硬直 0.4、饥饿 +10、潜行者秒杀、**自动追踪** |
| `Q` / 大招按钮 | 清空 Asn、敌军饥饿 +20、风险 +25%（耐药期 +35%），5s 强化 |
| `ESC` | 暂停菜单（继续/重开/退出） |

## 核心系统回顾

- **九关双难度**：普通通关解锁困难（⭐⭐），生成节奏按难度与关卡修正
- **五特殊敌人**：贪婪者（50px 吸取）/ 潜行者（150px/s 扑球+秒杀）/ 攻击者（红箭减速）/ 陷阱师（眩晕陷阱）/ 分裂者（死亡分裂 4 分裂体）
- **五道具**：爱心 / 净化 / 磁铁 / 连发（充能制）/ 护盾（免疫减速与眩晕）
- **救援信号弹**：正常细胞 25~35s 绿色光柱，赶到+饥饿/超时-饥饿
- **实体碰撞箱**：敌人/细胞阻挡玩家，冲刺无视
- **无尽模式**（9 关普通通关解锁）：30s 波次 + Boss 战 + 肉鸽三选一 + 永久成长 + 最高分
